# judo-throws

## Overview

Judo Throws is a lightweight browser-based training tool that helps judoka practice throw recognition and recall. It presents randomized throws from selectable throw groups and supports timed rounds, score-based training, and situation-based exercises with configurable throw combinations. Use it for focused solo practices.

## Bluetooth button

On Android, open the app in Chrome over HTTPS and tap **Bluetooth-Taster verbinden**. Select the BLE device named **Judo** in the browser's device picker. The button sends the same start/stop action as the current training mode's on-screen control. If the connection is interrupted, tap **Erneut verbinden** to pair again.
